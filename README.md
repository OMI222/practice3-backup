
# Практическая работа №3

## Автоматизация резервного копирования и проверка восстановления данных

**Студент:** Дыбыс Айбар Советбекулы
**Вариант:** 10

### Цель работы
Изучение резервного копирования, контроля целостности данных,
ротации резервных копий и автоматической проверки восстановления.

### Описание файлов
- make_test_data.py — создание 12 тестовых файлов
  в отделах office, shop1 и shop2.
- backup.py — резервное копирование, проверка SHA-256,
  ротация архивов и восстановление данных.
- rpo_rto.md — расчёт RPO и RTO для сети кафе.

### Запуск проекта

Создание тестовых данных:

    python make_test_data.py

Создание резервной копии:

    python backup.py

Восстановление из последнего архива:

    python -c "from backup import restore, BACKUP_DIR; restore(sorted(BACKUP_DIR.glob('backup_*.tar.gz'))[-1])"
